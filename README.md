# ZyntraAcesso

Aplicativo independente de acesso remoto, baseado no RustDesk de código aberto, com a identidade visual Zyntra.

**Em desenvolvimento. Ainda não existe instalador ZyntraAcesso validado nem servidor próprio disponível.**

- Conexão por número e senha permanente opcional, sem reconhecimento facial obrigatório.
- Controle de tela, teclado/mouse e arquivos pelos recursos do motor original.
- Acesso acompanhado com aviso de permissões e administração pela autorização nativa do Windows.
- Produto separado das contas, dados, assinatura e atualizadores do ERP Zyntra.

Consulte [escopo e requisitos de distribuição](ZYNTRAACESSO.md), [estado da preparação](docs/ENTREGA_ZYNTRAACESSO_2026-11-23.md) e [origem fixada](UPSTREAM.lock.json).

Base: [RustDesk 1.5.3](https://github.com/rustdesk/rustdesk/tree/1.5.3). A [licença AGPL-3.0](LICENCE), os créditos originais e as obrigações de código correspondente são preservados. A documentação original está em [UPSTREAM_README](docs/UPSTREAM_README.md).
